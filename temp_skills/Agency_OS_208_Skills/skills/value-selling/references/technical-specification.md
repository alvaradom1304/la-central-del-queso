# value-selling — criterios de ingeniería

ROI requiere beneficio neto respecto al costo relevante y periodo explícito. Para ventas adicionales usar contribución incremental, no facturación; para ahorro distinguir tiempo liberado de dinero efectivamente evitado. No sumar horas ahorradas y costo laboral evitado si representan el mismo efecto. Riesgo esperado necesita probabilidad/impacto sustentados, no una cifra arbitraria. Incluir implementación, licencias, soporte, supervisión y adopción. Sin baseline entregar modelo parametrizado y vacíos, no porcentaje ficticio. Comparar la alternativa de mantener situación actual y otras opciones suficientes.

## Caso adverso determinante

Una propuesta suma 10 horas liberadas como ahorro salarial y otra vez como capacidad adicional, y usa ingreso bruto para prometer ROI.

## Evidencia de aceptación

- Resolver el fallo específico con evidencia y límites
- No cerrar con contradicción material o resultado inventado
- Entregar criterios verificables y responsables operativos según alcance
