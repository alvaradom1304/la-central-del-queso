# Roadmap de implementación

| Sprint | Alcance | Checkpoint |
|---|---|---|
| 0 | Inventario, gaps y arquitectura | Límites y duplicados identificados |
| 1 | Skill system, contrato y fábrica | Schemas, validación y portabilidad |
| 2 | Research/Business | Procedimientos y fuentes; no inventar investigaciones |
| 3 | Venture/Finance | Fórmulas, datos/supuestos y gates |
| 4 | Sales/Marketing | Métodos separados y autorización de contactos |
| 5 | Brand/Creative | Estrategia, derechos y claims |
| 6 | Web/Security | Accesibilidad/performance y scope autorizado |
| 7 | AI/Automation | Herramientas reales, evals y supervisión |
| 8 | Operations/Growth | Operación antes de escala |
| 9 | Orchestrators | Dependencias y revisión contextual |
| 10 | Quality loop/Testing | Estructura en toda biblioteca; comportamiento en muestra crítica |
| 11 | Quesera | Prueba documental; campo pendiente de datos y operación real |

Construir y verificar por lotes secuenciales. Publicar skills experimentales no equivale a desplegar una aplicación cliente. Promover versiones solo con evidencia registrada. No publicar sitios, realizar gastos, contactar personas o alterar inventario real por construir esta biblioteca.
