# OpenSEO: Strategic Search & Intent Intelligence

Esta habilidad permite estructurar estrategias de posicionamiento orgánico analizando la intención del comprador y la arquitectura técnica del sitio.

## Flujo de Trabajo

1. **Mapeo de Intención de Búsqueda:**
   - **Transaccional:** Términos de compra inmediata (ej. *"comprar soporte laptop gamer costa rica"*, *"gadgets gaming envío gam sinpe"*).
   - **Informativa:** Comparativas y unboxings (ej. *"mejores accesorios para setup escritorio"*, *"luces barra monitor led valen la pena"*).
   - **Navegacional:** Búsqueda directa de marca (ej. *"el tilichero cr catalogo"*, *"la central del queso precios"*).

2. **Optimización On-Page Quirúrgica:**
   - Metadatos con OpenGraph dinámico y Twitter Cards.
   - Datos estructurados Schema.org (`Product`, `Offer`, `AggregateRating`, `Organization`, `LocalBusiness`).
   - URLs semánticas limpias y jerarquía `<h1>` única por página.

3. **Arquitectura y Rendimiento:**
   - Core Web Vitals en verde (LCP < 2.0s, CLS < 0.1, INP < 200ms).
   - Sitemap XML estático o dinámico e indexación rápida mediante Google Search Console.
