# 07 · Registro de activos y derechos: [cliente]

Todo activo que no sea código propio del proyecto: fuentes, imágenes, iconos, modelos 3D, vídeo, audio, librerías con licencia especial y textos de terceros. Sin licencia conocida, el activo no entra en la entrega. **[REVISIÓN PROFESIONAL]** cuando el uso sea comercial y la licencia sea dudosa.

| Activo | Uso en el proyecto | Fuente / autor | Licencia y versión | Permite uso comercial | Atribución exigida | Quién paga / titular | Evidencia (enlace o archivo) |
|---|---|---|---|---|---|---|---|
| | | | | sí / no / dudoso | | | |

Reglas:
- Material aportado por el cliente: el cliente declara que tiene los derechos (propuesta, §7).
- Contenido generado con IA: registrar la herramienta y sus términos, y no presentarlo como fotografía real del negocio.
- Licencias de pago: solo con autorización y quedan a nombre del cliente cuando corresponda.
- Si un activo no tiene evidencia de licencia, se sustituye antes de G5.
