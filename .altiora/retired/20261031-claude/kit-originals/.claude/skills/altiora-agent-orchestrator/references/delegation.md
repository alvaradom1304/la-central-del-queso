# Contrato breve para cada agente

El coordinador proporciona este paquete; no necesita pegar el historial completo.

- **Objetivo:** un resultado concreto conectado al encargo.
- **Entradas:** rutas o fuentes exactas y decisiones que el agente debe respetar.
- **Ámbito:** archivos que puede editar o indicación de solo lectura.
- **Dependencias:** qué debe recibir antes de empezar y qué otros agentes trabajan cerca.
- **Skills:** nombres y rutas reales, solo las que necesita.
- **Salida:** hallazgos, cambios, evidencias de comprobación y asuntos pendientes.
- **Cierre:** cuándo terminar o comunicar un bloqueo concreto. Sin delegación recursiva por defecto.

## Ejemplo de investigación

Comparar dos enfoques para el portón de La Central del Queso usando el brief y los catálogos existentes. Devolver necesidad resuelta, fuentes con revisión, coste operativo y límites. No instalar paquetes ni editar la web. Terminar al recomendar una prueba representativa y describir su incertidumbre.

## Ejemplo de ingeniería

Implementar la escena acordada únicamente en los archivos asignados. Usar las versiones compatibles ya elegidas. Entregar el cambio, instrucciones para verlo y las comprobaciones realizadas. Informar si una dependencia impide avanzar; no sustituir el stack por cuenta propia.

## Ejemplo de revisión

Revisar el cambio producido contra el brief y el flujo comercial afectado. Devolver problemas reproducibles con archivo y ubicación; distinguir lo observado de lo no probado. No rehacer la implementación ni volver a investigar todo el catálogo.

## Integración

El coordinador compara la salida con el encargo, inspecciona el cambio y acepta o solicita una corrección concreta. Repetir únicamente si queda una cuestión material. Registrar decisiones reutilizables en el proyecto, no informes extensos de cada conversación.
